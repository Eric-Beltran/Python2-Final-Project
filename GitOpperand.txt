1. How to PULL (Get updates from GitHub) (Ctrl + T)
Use this when you start your day or if you are working on a team and
others have updated the code.
 The Shortcut: Ctrl + T (Windows) or Cmd + T (macOS).
 The Menu: Go to Git > Pull.
 The Action: A dialog box will appear. Usually, you just click Pull.
PyCharm will merge any changes from the cloud into your local files.

2. How to PUSH (Send your work to GitHub)
This is a two-step process: you must Commit (save locally) before you Push
(upload).
Step A: Commit (The "Save" Step) (Ctrl + K)
    1. Open the Commit tab on the far left (or press Ctrl + K).
    2. Check the boxes next to the files you changed.
    3. Write a Message: In the text box, describe what you did (e.g., "Fixed
       login bug" or "Added data processing script").
    4. Click the Commit button (or click the arrow next to it and select
       Commit and Push to do both at once).
Step B: Push (The "Upload" Step) (Ctrl + Shift + K)
    1. If you didn't select "Commit and Push" above, go to Git > Push (or
       press Ctrl + Shift + K).
    2. Review the commits you are about to send.
    3. Click Push. Your code is now live on GitHub!
