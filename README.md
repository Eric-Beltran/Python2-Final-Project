# Python2-Final-Project
Python2 Final Project: Secure Student Management System
Group Members:
 - Ben Toebben
 - Caleb Mitchell
 - Eric Beltran
 - Jace Rushing

Current Features:
 - Basic navigation via Command Line Interface
 - Add items to a database
 - Read items from database
 - Register users as standard or admin.
 - Admins can create, edit, and delete student profiles.
 - Users can view their own student profiles.
 - Users are automatically linked to their personal student profile by matching emails.
 - Export student information to a csv
 - Generate visual plots for student grades

Libraries:
 - Json
 - RE
 - hashlib
 - matplotlib.pyplot
 - datetime
 - urllib
